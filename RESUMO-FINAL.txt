🧪 TESTE A API COM CURL:
================================================================================

# 1. REGISTRAR
curl -X POST http://localhost:5000/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"teste@example.com","password":"Senha123","name":"Teste"}'

# 2. LOGIN (copie o token retornado!)
curl -X POST http://localhost:5000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"teste@example.com","password":"Senha123"}'

# 3. CRIAR CLIENTE (cole seu token no lugar de TOKEN_AQUI)
curl -X POST http://localhost:5000/clients \
  -H "Authorization: Bearer TOKEN_AQUI" \
  -H "Content-Type: application/json" \
  -d '{"name":"João Silva","email":"joao@example.com"}'

# 4. LISTAR CLIENTES
curl -X GET http://localhost:5000/clients \
  -H "Authorization: Bearer TOKEN_AQUI"

# 5. DASHBOARD
curl -X GET http://localhost:5000/dashboard \
  -H "Authorization: Bearer TOKEN_AQUI"
