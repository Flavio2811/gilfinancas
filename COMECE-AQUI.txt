🔧 PARA INTEGRAR O BACKEND (OPCIONAL):
================================================================================

Se você quer rodar o backend também:

1. Instale Node.js: https://nodejs.org

2. Crie uma pasta:
   mkdir gil-financas-backend
   cd gil-financas-backend

3. Copie os arquivos:
   - server-backend.js
   - package-backend.json → renomear para package.json
   - .env-example → renomear para .env

4. Instale dependências:
   npm install

5. Inicie o servidor:
   npm start

Pronto! Servidor rodando em http://localhost:5000

🧪 TESTE A API:
================================================================================

Comando de login:
curl -X POST http://localhost:5000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"teste@example.com","password":"Senha123"}'

Comando para listar empréstimos:
curl -X GET http://localhost:5000/loans \
  -H "Authorization: Bearer SEU_TOKEN_AQUI"
