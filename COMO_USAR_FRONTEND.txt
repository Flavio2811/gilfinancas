================================================================================
PASSO 1: PREPARAR PASTA DO FRONTEND
================================================================================

1. Crie uma pasta chamada "financeiro-frontend" no seu computador

2. Copie esses arquivos PARA DENTRO da pasta:
   - frontend-package.json (renomear para package.json)
   - App.jsx
   - App.css
   - main.jsx
   - index.html
   - vite.config.js

ESTRUTURA FINAL:
financeiro-frontend/
├── package.json
├── App.jsx
├── App.css
├── main.jsx
├── index.html
└── vite.config.js

================================================================================
PASSO 2: INSTALAR DEPENDÊNCIAS
================================================================================

1. Abra CMD ou PowerShell na pasta "financeiro-frontend"

2. Execute:
   npm install

Vai instalar React, Vite, Axios e tudo mais que precisa!

================================================================================
PASSO 3: INICIAR O FRONTEND
================================================================================

1. Na pasta "financeiro-frontend", execute:
   npm run dev

2. O navegador vai abrir automaticamente em:
   http://localhost:3000

================================================================================
PASSO 4: USAR O APP
================================================================================

1. TELA DE LOGIN (ao abrir):
   - Email: teste@example.com
   - Senha: Senha123

   OU crie uma conta nova clicando em "Criar agora"

2. DASHBOARD:
   - Mostra resumo total de empréstimos
   - Total de clientes
   - Empréstimos ativos

3. CLIENTES:
   - Adicione novos clientes
   - Veja lista de clientes cadastrados
   - Cada cliente mostra: Nome, Email, Telefone

4. EMPRÉSTIMOS:
   - Crie novos empréstimos
   - Selecione um cliente
   - Escolha valor, taxa de juros, tipo (simples/compostos)
   - Escolha período (diário/semanal/quinzenal/mensal)
   - Veja lista de empréstimos criados

REQUISITOS PARA FUNCIONAR
================================================================================

⚠️  IMPORTANTE: Você PRECISA estar rodando o BACKEND também!

1. Terminal 1: Backend rodando
   - Pasta: financeiro-app
   - Comando: npm start
   - Porta: 5000

2. Terminal 2: Frontend rodando
   - Pasta: financeiro-frontend
   - Comando: npm run dev
   - Porta: 3000

Se o backend não estiver rodando, o frontend não consegue se conectar!

================================================================================
TROUBLESHOOTING
================================================================================

❌ "Erro ao conectar com backend"
→ Verifique se o backend está rodando (npm start na pasta financeiro-app)

❌ "Erro de CORS"
→ O backend já tem CORS configurado, não precisa fazer nada

❌ "Página em branco"
→ Abra o console (F12) e veja qual erro aparece
→ Reinicie com: npm run dev

❌ "npm command not found"
→ Instale Node.js primeiro (https://nodejs.org)

❌ "Porta 3000 já está em uso"
→ Mude em vite.config.js: port: 3001
