🆘 SE TIVER ALGUM ERRO:
════════════════════════════════════════════════════════════════════════════

❌ "Node.js não foi encontrado"
→ Baixe Node.js em: https://nodejs.org (escolha LTS)
→ Instale e reinicie o computador
→ Rode setup.bat novamente

❌ "Port 5000 already in use"
→ Outra aplicação está usando a porta 5000
→ Opção 1: Feche a outra aplicação
→ Opção 2: Abra PowerShell e rode:
   npm start -- --port 5001

❌ "Cannot find module"
→ Rode setup.bat novamente
→ Certifique-se que tem internet para baixar os pacotes

❌ Nada funciona!
→ Abra um PowerShell nesta pasta e rode:
   npm install
   npm start
